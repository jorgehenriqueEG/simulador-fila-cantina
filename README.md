# Simulador fila cantina
## Descrição do Problema
Simular a fila de alunos na cantina da universidade, calculando o tempo de espera de cada um com base na eficiência do atendente.
## Requisitos
- Listar os alunos na ordem de chegada
- Calcular o tempo de espera de cada aluno
- Identificar o aluno com maior tempo de espera
## Exemplo de Uso
entrada = [("Ana", 15), ("Beto", 20), ("Carla", 10)]
Saída:
Ana: 0 min
Beto: 15 min
Carla: 35 min
Maior espera: Carla (35 min)
